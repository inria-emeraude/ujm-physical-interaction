# Digital Fabrication

## Pick up a CAD software

* If you're looking for a graphics-based engineering-oriented solution, FreeCAD is probably what you want:
    * FreeCAD Website: <https://www.freecad.org/>
    * FreeCAD Tutorials: <https://wiki.freecad.org/Tutorials>
* If you're looking for a code-based engineering-oriented solution, OpenSCAD is probably what you want:
    * OpenSCAD Website: <https://openscad.org/>
    * OpenSCAD Tutorials: <https://openscad.org/documentation.html>
* If you're looking for a graphics-based slightly more abstract solution, Blender is probably what you want:
    * Blender Website: <https://www.blender.org/>
    * Blender Tutorials: <https://www.youtube.com/results?search_query=%23b3d+tutorial&sp=EgIIBQ%253D%253D>
    
## Tutorials

* Try to follow the first few tutorials of one of these environments.

## Designing a 3D printable object

* Design a 3D printable object. It can be anything you want: a little statue, something to put on a necklace, an enclosure for one of your interfaces/controller, a holder, etc.
* Make sure that this object is printable on a basic printer such as an Ultimaker 2 Extended using Cura. For that, you should export your design as an STL file and open it in Cura. If your object needs support material, make sure to include it.
