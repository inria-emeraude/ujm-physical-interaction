# Sensors

## Digital Sensors

* Some sensors (such as some accelerometers, the distance sensor in your kits, etc.) can communicate directly with the Arduino digitally using the i2c protocol. Several i2c sensors can be connected on the same port. The following tutorial gives a good overview of how i2c works: [https://learn.sparkfun.com/tutorials/i2c/introduction](https://learn.sparkfun.com/tutorials/i2c/introduction)
